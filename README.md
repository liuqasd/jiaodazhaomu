# 交大招募 — SWJTU 校园招募小程序

🎓 西南交通大学校园招募信息平台（微信小程序），连接社团/组织与学生。

## 功能

- 📢 **招募信息发布** — 社团和组织发布招新信息
- 🔍 **浏览与搜索** — 按类别、关键词筛选感兴趣的招募
- 📋 **在线报名** — 一键提交报名信息
- 👤 **个人中心** — 管理我的报名记录
